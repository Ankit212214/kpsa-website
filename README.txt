# KPSA GROUP OF COMPANY — Complete Static Website

## Files
- index.html — Home
- about.html — About
- services.html — Services
- projects.html — Projects
- contact.html — Contact
- styles.css — responsive styling
- script.js — mobile menu + WhatsApp enquiry
- assets/ — logo and replaceable visual assets

## Run on Windows
1. Extract the ZIP.
2. Double-click `index.html`.
3. The website opens in Chrome.
4. For editing, use VS Code (recommended) or Notepad.

## Important before publishing
- Replace sample project images with actual KPSA project photos.
- Confirm phone, email, address, GST and legal/company details.
- The enquiry form uses WhatsApp; it does not store enquiries in a database.
- If you want an admin panel, database, login, lead management and quotation system, build a backend separately.

## Publish with GitHub Pages
GitHub Pages can host a static site directly from a repository. Create a repository, upload these files, then enable Pages from repository Settings > Pages. Official documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages

## Custom domain
If you own `kpsagroup.com`, GitHub Pages supports custom domains. Configure the domain in repository Settings > Pages first, then set the required DNS records at your domain provider. DNS changes can take up to 24 hours.
Official documentation:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
